Sobre o Projeto Powerpolis

O Powerpolis é a solução da equipe G9-BR-TEAM-12 para o desafio EnergiAI: uma aplicação que recebe dados de consumo energético (kWh mensal, uso em horário de pico, quantidade de equipamentos, tipo de imóvel, horas de alto consumo) e classifica o perfil em Eficiente, Moderado ou Ineficiente, gerando recomendações de otimização e estimativa de custo mensal via API REST, com integração obrigatória à Oracle Cloud Infrastructure (OCI).
